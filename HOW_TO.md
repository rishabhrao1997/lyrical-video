PROMPT: lyric video in one prompt (Claude Code)

What you need
1. Claude Code installed and signed in (claude.ai/code).
2. A song file you own (iTunes purchase, your own track). Streaming downloads won't work.
3. Optional: a lyrics .txt (one sung line per row) for perfect words.
4. Optional: 10-20 free clips from pexels.com in one folder (search moods like "rain window night", "empty street night").

How to run
1. Make a new folder, open Terminal in it, type: claude
2. Paste the prompt from PROMPT_share.md and fill in the [brackets].
3. Wait 20-30 minutes. You get final_silent.mp4 and preview_with_audio.mp4.
4. Posting on Instagram: upload final_silent.mp4 and add the song from Instagram's music library at the same start time.

Tips
- Pick a 40-75 s part of the song: the chorus or climax.
- The more specific your MOOD line, the better the look.
- Only post songs that are in Instagram's music library.
